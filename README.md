# Planfaktor

Plan-driven конвейер ролей, целиком в ZCode, без рантайма.

План течёт сам — как брёвна при молевом сплаве: работу несёт течение процесса
(статусы, роли, гейты), а не движок. Routing truth — статусы в файлах планов,
не память чата.

Статус: сутки на первый рабочий прогон (корпус + команды + субагенты + dogfood).
Рабочие материалы валидации — в `.tmp/` (в git не входят).
